# Практическая работа 2 — форматированный вывод

Учебная программа на C для практики вывода через **printf**, простых вычислений и форматирования чисел.

## Что делает программа

- Показывает перевод строки и отступы.
- Печатает целые и вещественные числа с заданной шириной и точностью.
- Демонстрирует деление, остаток от деления и умножение.
- Считает минуты суток, время до полуночи и секунды после 8:00.
- Форматирует дробь для варианта 3.
- Считает плотность населения в домашнем задании.

## Вариант 27

В таблице задания 2.3 — 24 варианта. После полного круга номер 27 соответствует варианту 3.

| Параметр | Значение |
| --- | ---: |
| n | 4 |
| L | 337 |
| k | 5 |
| m | 3 |

В домашнем задании используется пример: 10000 жителей на площади 100 км². Плотность равна 100 человек на км².

## Важные значения в программе

В начале файла заданы **N = 8** и **K = 2**, то есть время 8:02. Перед запуском замени эти два значения на часы и минуты, которые нужно посчитать. Например, для 10:15 укажи **N = 10** и **K = 15**.

Для времени 8:02 программа получает 482 минуты от начала суток, 15 часов 58 минут до полуночи и 120 секунд после 8:00.

Пример вычисления доли часа:

```c
K / 60.0
```

Десятичная точка в числе **60.0** нужна, чтобы ответ мог быть дробным.

> В методическом опыте одна строка передаёт вещественные значения в формат **%d**, который предназначен для целых чисел. Visual Studio может показать предупреждение, а результат этой строки не гарантирован. Строка оставлена как часть опыта с форматами из задания.

## Запуск

1. Открой файл **Практика_2.vcxproj** в Microsoft Visual Studio.
2. При необходимости измени значения **N** и **K**.
3. Нажми **Ctrl+F5** — запуск без отладки.
4. Посмотри результаты в консольном окне.

Вводить данные с клавиатуры не нужно. Программа использует значения, записанные в начале кода.
